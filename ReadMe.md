# Hotel PMS Room Auto-Assignment Engine

실제 비즈니스/시티 호텔의 층별 물리적 건축 레이아웃과 도메인 규칙을 정밀하게 모델링하고, **2-Pass 파이프라인(Hard Filter + Soft Scoring)** 및 **연박(Long-stay) 가중치 알고리즘**을 통해 최적의 객실을 선제적으로 배정하는 순수 Java 기반 PMS(Property Management System) 코어 엔진입니다.

---

## 1. 프로젝트 개요 (Overview)

* **언어 및 환경**: Java 17+
* **아키텍처 원칙**: 순수 도메인 주도 설계(DDD) 지향, 외부 라이브러리 의존성 없는 Plain Java 구조, 와일드카드 없는 명시적 Import, 단일 진실 공급원(Single Source of Truth) 보장
* **핵심 목표**:
    1. 결번(금기 번호, 설비실) 및 층별 특수 구조를 포함하는 **실제 호텔 도면(총 191실) 완벽 매핑**
    2. 오버부킹과 환각(Hallucination)을 원천 차단하는 **불변 계약 검증(Hard Filter)**
    3. 고객 선호도 및 체류 기간에 기반한 **다차원 채점 엔진(Soft Scoring)** 구축
    4. 비정형 자연어 요청 처리를 위한 **확장 가능한 파이프라인 분리**

---

## 2. 객실 물리 구조 및 도메인 사양 (Room Specs)

3층부터 15층까지 총 13개 객실 층으로 구성되며, 서양권 금기 번호 및 설비 배치를 고려한 결번 규칙을 적용하여 **총 191실**을 유지합니다.

### 층별 및 호실 구성표
| 구분 | 해당 층 | 층당 호수 범위 | 결번 규칙 | 실질 객실 수 |
| :--- | :--- | :--- | :--- | :--- |
| **일반 객실층** | 3층 ~ 13층 (11개 층) | 01호 ~ 16호 | **13호 전 층 결번** (서구권 금기 번호) | 15실 × 11 = **165실** |
| **상층부 특수층** | 14층 ~ 15층 (2개 층) | 01호 ~ 16호 | **13호 결번** + **03호, 07호 추가 결번** | 13실 × 2 = **26실** |
| **총계** | **13개 층** | - | - | **총 191실** |

### 호실별 타입 및 물리 속성 매핑
* **`01호, 14호`**: 슈페리어 트윈 (`SUPERIOR_TWIN`)
* **`02호, 09호`**: 레지덴셜 더블 (`RESIDENTIAL_DOUBLE`)
* **`05호, 06호, 10호, 11호`**: 슈페리어 더블 (`SUPERIOR_DOUBLE`)
* **`04호, 08호`**:
    * 13층 이하: 모더레이트 더블 (`MODERATE_DOUBLE`)
    * 14층 이상: 이그제큐티브 더블 (`EXECUTIVE_DOUBLE`)
* **`12호, 15호, 16호 및 03호, 07호(일반층)`**: 모더레이트 더블 (`MODERATE_DOUBLE`)
* **엘리베이터 인접 구역**: `03호 ~ 08호` (보행 약자 접근성 높음 / 소음 민감 구역)
* **코너룸 구역**: `01호, 02호, 09호, 14호, 16호` (측면 창 및 인접 객실 소음 최소화)
